智慧巡检实现无人值守
变电站智慧巡检解决方案

变电站是电力系统中对电压和电流进行变换、接受及分配电能的场所，工作人员要定期对变电站内断路器、隔离开关、电表等仪表进行巡检以保障变电站稳定运行。ARIS-OS室外巡检机器人，通过双光云台和多种传感器，配合后台AI视觉算法，可自主完成场站内目标物的智能化巡检，解决室外巡检劳动强度大的问题。

场景痛点

  • 室外变电站巡检距离较长，工作繁重，受天气影响较大，工作强度大。
  • 人工巡检依赖个人经验、技能和素质，缺少实时判断依据，容易错检漏检，同时缺乏环境动态感知能力，容易造成事故隐患。
  • 人工巡检数据难以实时电子化和信息化，缺失长期的巡检记录，不便于研读故障趋势。

解决方案一

变电站巡检
巡检机器人 ARIS-OS

扫码观看视频

产品介绍

OS系列是一款针对室外变电站研发的巡检机器人，融合自主导航定位、非接触检测、多传感器融合、后台大数据分析等技术，在变电站等室外场景，针对不同高度和位置的表计读数、开关位置、设备温度等状态以自主或遥控方式进行巡检，实现无人值守，保障人员安全。

实现功能

  • 双光云台
  • 多线激光雷达+SLAM算法
  • 仪表识别
  • 紧急定位
  • 安全雷达+超声传感器+防跌落+防撞条
  • 多模式巡检
  • 噪声检测

方案优势

环境适应性强

能克服雨雪冰霜等不良天气，正常进行巡检作业，较大车轮尺寸越障性能好。

智能识别

可自主规划巡检线路，智能识别人员、车辆、异物入侵等状态，提升安全性。

实时监测

24小时常态化监测设备运行状态及运行坏境，实时回传红外画面。

一键顺控

摄像头自动识别记录并分析各指示状态，可优化传统人工倒闸操作模式，降低工人运维及人身风险。

应用案例

案例一
国家能源集团国家电力某电厂

项目概括

PROJECT OVERVIEW

国家能源集团国电电力某电厂位于鄂尔多斯市鄂托克前旗，该地干旱、风沙大、日照长、辐射强、温差大，自然环境极为恶劣。为响应国家“西电东送”“国家大气污染防治计划”和“煤电节能减排升级与改造行动计划”号召，应用优小二智慧电厂巡检解决方案，助力上海庙电厂打造世界一流智慧火电工程。

方案描述

SCHEME OVERVIEW

优小二升压站巡检解决方案包括室外轮式机器人、数据采集功能模块、供电及通信系统、软件监控平
台等，采用厂内5G专网通讯方式，及时回传现场整体运行画面，对全站设备外观、指示灯状态、环境
状况、变压器开关状态、环境噪音等指标进行智能化全时监测。

任务执行：125次

PROJECT OVERVIEW

国电和风某风电厂位于辽宁省锦州市黑山镇，该地区冬春季节天气寒冷，环境恶劣，人工运维难度大、成本高。为解决人工室外运维难题，电厂决定导入机器人实现无人值守。
