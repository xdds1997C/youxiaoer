建设全流程物流自动化
新能源行业解决方案

行业痛点

  • 物料重，人工搬运劳动强度大，招工难问题突出。
  • 人员进出带来粉尘污染影响良率，人工搬运出错导致原料损耗。
  • 人工搬运不稳定导致前后工序衔接不够，影响节拍浪费产能。

方案价值及优势

  • 适应7*24H作业，根本解决用工问题。
  • 0污染，保障原料质量，稳定安全搬运，降低原料损耗。
  • 高效协同，提升产线稼动率，柔性调度降低库存水位，降低成本。

应用案例

案例一
国内锂电头部G企业正负极车间智能物流改造项目

项目概括

PROJECT OVERVIEW

国内锂电头部G企业拥有完整的锂电行业生态链，覆盖上中下游及回收循环，该企业某正负极车间面积约20000m，涵盖正负极的涂布上料至涂布下料等物料转运搬送，车间招工难问题突出，希望通过导入机器人实现涂布-辊压-分切-模切-烘烤-切叠全流程物流自动化改造，解决招工难问题。

解决方案

SOLUTION

导入24台多机型移动机器人协同作业，实现涂布到切叠的全流程物流自动化改造。其中，8台大极卷搬运机器人用于涂布上下料及FTT上下料，9台小极卷搬运机器人用于辊压/模切/切叠上下料，7台顶升机器人用于烘烤上下料。

效益呈现

BENEFIT PRESENTATION

工作效率：24台机器人1天执行2267趟任务，日作业里程172526m，搬运物料1774次

效益提升：◎投资回收期＜2年 ◎库存周转率提升2% ◎产能提升1%

案例二
全球电池领先企业L公司某电极车间物流自动化改造项目

项目概括

PROJECT OVERVIEW

全球电池领先企业L公司某工厂主要生产动力电池，其电极车间内卷料的来回周转，人工作业面临劳动强度过大以及物料更新不同步问题，工厂希望通过导入机器人实现分切段物流自动化，解决上述问题。

解决方案

SOLUTION

导入10台顶升搬运机器人，实现卷料在电极车间分切设备与缓存物料室之间的全自动化往
复搬运。使用YOUIFLEET系统完成多台机器人的路径规划和任务调度，YOUITMS对接车间
MES系统，实现物料管理、工车载具管理，库位管理，车间自动化物流看板等功能。

效益呈现

BENEFIT PRESENTATION

工作效率：10台机器人1天执行192趟任务，日作业里程15360m

效益提升：◎满足7*24H生产 ◎投资回收期＜2年
